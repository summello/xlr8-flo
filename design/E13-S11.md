# E13-S11 — Internal versus vendor-facing notes and attachments on a PO, enforced by test

**Epic** E13 · **M3** · **security/M** · after **E13-S09**, **E09-S10** · tags: `security` (Opus review)

> **Conventions:** `docs/m1-conventions.md`, `docs/m2-conventions.md`, `docs/author-traps.md`.
> **Decisions:** canvas DECISIONS 171 (a note marked `Sent to Vendor` appears on the PDF; **an uploaded
> file is never sent in M3**: "Not sent until scanning is available"; D-M2-8, D-14, E19-S04), 170.
> `design-system/pages/purchase-orders.md` §2 "What the supplier receives".

## Requirements (inlined)

- **PO-017** — POs must support notes, terms, supporting attachments, and vendor-facing attachments. Internal-only content must never be included accidentally.
- **EML-005** — Vendor-facing email must never include internal-only notes or attachments (PO-017); this must be covered by an automated test.
- **COL-002** — Notes must identify author and visibility, including internal-only versus externally shareable.

## Design

Register `purchase_order` with collaboration's `register_document_access` (read
`purchase_order.view`, write `purchase_order.create` while draft and `purchase_order.amend` after).
Notes use E09-S10's existing `visibility`. **Map it:** only the visibility value that E09-S10 calls
external/shareable counts as `Sent to Vendor`, and **internal is the default**. Changing a note to
`Sent to Vendor` after issue applies to the next version only (the issued snapshot is immutable,
E13-S06).

`vendor_copy()` (E13-S08) reads `Sent to Vendor` notes **through one function**,
`collaboration.service.external_notes_for("purchase_order", id)`. Add it if it does not exist; it
filters in SQL. Attachments are **never** included in M3, whatever their flag: `vendor_copy` lists
each vendor-flagged file as "Not sent until scanning is available" and attaches nothing (decision 171).

## Acceptance

- [ ] **EML-005 test with planted violations:** seed an internal note, a `Sent to Vendor` note, an internal attachment and a vendor-flagged attachment, each with distinctive text; issue; assert the outbox email (body and attachments) and the PDF text contain the `Sent to Vendor` note only, no attachment bytes, and none of the internal text. Plant (a): read all notes in `vendor_copy` → fails. Plant (b): attach a vendor-flagged file → fails.
- [ ] A note flipped to `Sent to Vendor` after issue appears only in the next version's PDF.
- [ ] The author and visibility are shown on every note read (COL-002).
- [ ] TEN-010; `flo check` green.
