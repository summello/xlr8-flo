# E16-S01 — Custom field definitions: typed, scoped, effective-dated, ordered, retire-not-delete

**Epic** E16 · **M4** · **engine/L** · after **E05-S03** · tags: none (ungated)

> **Conventions:** `docs/m1-conventions.md`, `docs/m2-conventions.md`, `docs/author-traps.md`.
> **Decision D-12** (`docs/claude-plan.md` §1): custom fields are **relational definitions plus JSONB
> values, not EAV**. This story is the definitions half; values, indexes and searchable columns are
> E16-S02. Back end only; the administration screen is a registered **GAP**
> (`docs/ui-screen-inventory.md` §3.3).
> **Writes:** every `PATCH`/`PUT`/`DELETE` on an editable resource follows `docs/m2-conventions.md` §O (`If-Match` with the integer version, `ETag` on reads, 400 when missing, 409 `stale_version` on mismatch). `Idempotency-Key` protects **POST** commands only.
> **RLS:** every new tenant table gets literal `ALTER TABLE <t> ENABLE ROW LEVEL SECURITY; … FORCE …; CREATE POLICY tenant_isolation ON <t> …` statements in the migration text, one block per table, never generated by a helper or f-string.

## Requirements (inlined)

- **CUS-001** — Authorized administrators must be able to add typed custom fields to supported document types without a code deployment.
- **CUS-002** — Field types must include text, number, money, date/time, boolean, single/multi-select, and reference where feasible.
- **CUS-003** — Definitions must support label, help text, required status, default, validation, scope, effective dates, display order, and permissions.
- **CUS-010** — Deleting a field with historical values must be prohibited; it may be retired and hidden from new entry.
- Context for later stories, not closed here: CUS-007 (a definition change must not silently reinterpret history: this story makes `key`, `document_type` and `field_type` immutable, which is the precondition), CUS-008 (sensitive fields, E16-S03).

## Design

New module `modules/customfields/` (`models.py`, `schemas.py`, `service.py`, `validation.py`).

**Supported document types** (a closed constant `DOCUMENT_TYPES` in `service.py`; adding one is a
one-line change in the story that needs it): `project`, `requisition`, `requisition_line`,
`vendor`, `rfq`, `purchase_order`, `purchase_order_line`. They are strings here; this module imports
no document module.

**Table `custom_field_definition`** (RLS):

| Column | Rule |
|---|---|
| `id uuid`, `org_id` | |
| `document_type text` | CHECK in `DOCUMENT_TYPES`; immutable |
| `key text` | `^[a-z][a-z0-9_]{0,62}$`; `UNIQUE (org_id, document_type, key)`; immutable; never reused after retirement |
| `field_type text` | CHECK in `text, number, money, date, datetime, boolean, single_select, multi_select, reference`; immutable |
| `label text` | 1..120 after trim |
| `help_text text` | 1..500 after trim, **required** (XFN-008: every field has help) |
| `required bool` | default false |
| `default_value jsonb NULL` | validated by `validate_value` against this definition; not allowed for `reference` |
| `validation jsonb NOT NULL DEFAULT '{}'` | per type, below; unknown key → 422 |
| `unit_id uuid NULL` | NULL = organization-wide; else an active BU/OU (applies to documents of that unit and its descendants) |
| `effective_from date NOT NULL`, `effective_to date NULL` | `effective_to ≥ effective_from` (reuse `org.service.validate_master_dates`) |
| `display_order int NOT NULL` | 0..10000 |
| `read_permission text NULL`, `edit_permission text NULL` | each must be a catalogue permission code (`identity.service.is_permission_code`, added by this story); NULL = the document's own permissions. **Stored only; enforcement is E16-S03.** |
| `searchable bool`, `reportable bool` | stored flags for CUS-009; E16-S02 builds the index/column from them |
| `retired_at timestamptz NULL`, `retired_by` | |
| `version int NOT NULL DEFAULT 1` | §O |

**A BEFORE DELETE trigger raises** on `custom_field_definition` (CUS-010 by construction: there is
no delete path at all, and E16-S02's values will reference definitions). Retirement is the only
end of life.

**Validation keys per type** (`validation.py`, Decimal only, amounts and bounds as decimal strings):

| Type | Keys | Value shape (for defaults now, values in E16-S02) |
|---|---|---|
| `text` | `min_length` 0..2000, `max_length` 1..2000 (default 200) | string |
| `number` | `decimal_places` 0..4 (default 0), `min`, `max` | decimal string, at most `decimal_places` places |
| `money` | `currency` (ISO 4217 via `org.service.validate_currency`, or absent = the document's currency), `min`, `max` | `{"amount": "<decimal string>", "currency": "XXX"}`; amount has at most the currency's places (`kernel.money.currency_exponent`); more → 422, never silently rounded; a value in another currency than a fixed `currency` → 422 |
| `date` / `datetime` | none | ISO date / RFC 3339 instant with offset |
| `boolean` | none | `true`/`false` |
| `single_select` / `multi_select` | `options: [{code, label, retired}]` 1..200, codes `^[A-Z0-9_]{1,40}$` unique; `max_selected` (multi, 1..200) | option code / list of distinct codes; a retired option is refused for new values |
| `reference` | `target`: `master:<kind>` for a kind accepted by `org.service.known_kind`, or `vendor`, or `project` | uuid (resolved in E16-S02) |

Options: a PATCH may add options, relabel them and retire them; it may **not** remove or recode an
option (422 `option_removed`), because history points at codes.

**Service contract for E16-S02..S06 (frozen once merged):**

```python
def definitions_for(conn, scope, document_type: str, unit_id: UUID | None, on: date) -> list[FieldDefinitionRead]
    # active for new entry: not retired, on ∈ [effective_from, effective_to], unit NULL or unit_id within its subtree;
    # ordered by (display_order, key)
def get_definition(conn, scope, id: UUID) -> FieldDefinitionRead          # includes retired
def validate_value(definition: FieldDefinitionRead, value: JsonValue) -> JsonValue   # normalized, or ProblemError 422
```

## API (`api/customfields.py`, prefix `/api/v1/custom-fields`)

| Method and path | Guard | Behaviour |
|---|---|---|
| `GET /` | `require_granted("master.read")` | `?document_type=&include_retired=false&on=` → definitions the org holds, organization-wide ones plus those whose `unit_id` is within the caller's granted units (all when `org_wide`), ordered `(document_type, display_order, key)`. |
| `GET /{id}` | `master.read` at the organization | `ETag`. Foreign → 404. |
| `POST /` (Idempotency-Key) | `master.manage` at the organization | 201. Duplicate key → 409 `duplicate_key` (also when the existing one is retired). |
| `PATCH /{id}` | `master.manage` | `If-Match`. Editable: `label, help_text, required, default_value, validation` (options rules above; bounds may change), `unit_id, effective_from, effective_to, display_order, read_permission, edit_permission, searchable, reportable`. `key`, `document_type`, `field_type` → 422 naming the field. Retired → 409 `retired`. |
| `POST /{id}/retire` (Idempotency-Key) | `master.manage` | `If-Match`. Sets `retired_at`. Already retired → 409 `already_retired`. |

Why the master-data permissions: definitions are organization configuration like the master lists,
and CUS-001 says "authorized administrators"; `master.manage` is held by `organization-administrator`
only, `master.read` by every operational baseline role. No new permission, no permissions migration.

Audit: `custom_field.create`, `custom_field.update` (before/after of changed columns),
`custom_field.retire`.

## Acceptance

- [ ] Migration up/down with data preservation; `test_migrate.py` lists it; a raw `DELETE` on a definition raises.
- [ ] Each of the nine types creates with a valid default and rejects an invalid one (table-driven test, one bad case per type, 422 naming `default_value`).
- [ ] `number` with `decimal_places: 2` accepts `"12.34"`, rejects `"12.345"` and the JSON number `12.34` (decimal strings only).
- [ ] `money` default `{"amount": "10", "currency": "JPY"}` is accepted; `"10.5"` JPY → 422; `"1.234"` KWD accepted, `"1.2345"` KWD → 422.
- [ ] PATCH that drops an option → 422 `option_removed`; retiring an option → 200 and `validate_value` refuses it.
- [ ] `key` / `document_type` / `field_type` in PATCH → 422; stale `If-Match` → 409; retired → 409.
- [ ] `definitions_for` excludes retired, not-yet-effective, ended and other-subtree definitions and orders by `(display_order, key)` (golden list).
- [ ] Authorization: org admin 201; a project-manager (holds `master.read`, not `master.manage`) → 403 on POST/PATCH/retire, 200 on GET; foreign tenant → 404.
- [ ] TEN-010 entries; generated client regenerated; `flo check --light` green; `customfields` added to `MONEY_MODULES` in `check_money_floats.py`.
