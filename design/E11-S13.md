## Design

A `Tax and Banking` card on `/vendors/:id`, in the grid slot E11-S12 leaves for it.
- **Masked:** values from the detail response (`•••• 4821`) in the mono face with +0.04em tracking (MASTER §7.15), so the width does not change on reveal.
- **Restricted:** when the response says `restricted: true`, the card reads `Restricted` and who to ask (the role label from the server).
- **Reveal Values** appears only when the server lists `vendor.sensitive.reveal` in the caller's allowed actions. It calls `POST /vendors/{id}/sensitive/reveal`, then shows the values and `Revealed by you, 14:02. Logged.` (time in the user's locale).
- **Re-mask** after 60 s (a constant named `REVEAL_SECONDS`, with a `ponytail:` naming open question E11-S08 #3), or when focus or the pointer leaves the card, whichever comes first. Re-masking **drops the values from React state and the DOM**; it does not hide them with CSS.
- **Edit** (holders of `vendor.edit` and reveal): an inline form that never pre-fills the full values without a reveal first.
- The values never go into the page title, `aria-live` text, a `console` call, the URL, `localStorage`, or the query cache. Fetch with the query client's `gcTime: 0` and never key the result into a shared cache.
