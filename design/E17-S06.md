## Design

### Storage

`identity_preference` (**not** tenant-scoped, like `identity`: one person, many orgs; no `org_id`,
so the tenancy gate does not apply): `identity_id uuid PRIMARY KEY` (FK `identity`),
`locale text NULL`, `time_zone text NULL`, `theme text NOT NULL DEFAULT 'system'` CHECK in
`light, dark, system`, `version int NOT NULL DEFAULT 1`, `updated_at`. NULL locale / time zone =
use the browser's.

`user_grid_preference` (RLS, per organization, because saved grid views name the org's units and
statuses): `org_id`, `user_id`, `grid_id text` (`^[a-z0-9][a-z0-9._-]{0,63}$`),
`preferences jsonb NOT NULL` (the existing `GridPreferences` shape, ≤ 64 KB, CHECK on
`octet_length(preferences::text)`), `updated_at`. `PRIMARY KEY (org_id, user_id, grid_id)`.

Validation (server, stdlib only, no new dependency):
- `locale`: BCP 47 shape `^[a-z]{2,3}(-[A-Z][a-z]{3})?(-([A-Z]{2}|[0-9]{3}))?$`, ≤ 35 chars.
- `time_zone`: `in zoneinfo.available_timezones()`.
- grid `preferences`: `density` ∈ `comfortable, compact`; `views` a list ≤ 50, each an object with
  string `id` and `name`; the rest of each view is stored as given (the web owns its shape, and
  `isView` in `grid-preferences.ts` already discards malformed views on load).

### API (next to `/me` in `api/auth.py`, or `api/me.py` if E22-S07 created it)

| Method and path | Guard | Behaviour |
|---|---|---|
| `GET /api/v1/me/preferences` | `require_member()` | 200 `{locale, time_zone, theme, version}` with `ETag`; defaults when no row. |
| `PATCH /api/v1/me/preferences` | `require_member()` | `If-Match` per §O (version 0 = no row yet). Any subset of `locale` (or `null`), `time_zone` (or `null`), `theme`. 422 per field. Audited `identity.preference.set` in the current org (the E22-S07 rule for global identity data). |
| `GET /api/v1/me/grid-preferences/{grid_id}` | `require_member()` | 200 `{grid_id, preferences}`; `DEFAULT_GRID_PREFERENCES` equivalent when absent. |
| `PUT /api/v1/me/grid-preferences/{grid_id}` | `require_member()` | Replaces the document; idempotent by semantics (§C). **Not audited**: it is per-user view state, not a record (XFN-003 "without altering shared records"), it is written on every column resize, and the audit log is the Neon 512 MB budget's largest consumer. This packet overrides convention C's "each write audits" for this route only. |

Every route reads or writes only the caller's own rows, filtered in SQL by the session identity.

### Web

1. `apps/web/src/lib/preferences.ts`: load `GET /me/preferences` once in the shell after sign-in;
   expose `usePreferences()`; until it resolves, the browser defaults apply (no blocking spinner).
2. `apps/web/src/lib/format.ts`: `formatDate(iso)`, `formatDateTime(iso)`, `formatTime(iso)`,
   `formatNumber(n)`, each `Intl` formatter built with `{locale ?? undefined, timeZone: time_zone ??
   undefined}`, cached per (locale, zone, options). Replace every `Intl.DateTimeFormat(undefined, …)`,
   `toLocaleString()`, `toLocaleDateString()` call in `apps/web/src` (except `_dev` galleries and the
   locale-independent exponent reads in `lib/decimal.ts`) with these, and pass the preference locale
   to `lib/money.ts`. **Date-only values** (`YYYY-MM-DD`, e.g. `need_by`, `valid_until`) are formatted
   as calendar dates with `timeZone: "UTC"` from `T00:00:00Z`, never shifted by the user's zone.
3. Theme: `setThemePreference` also PATCHes the server; on load a server theme that differs from
   `localStorage` wins and is written back to `localStorage` (the blocking first-paint read keeps
   using `localStorage`, so there is no flash).
4. Grid: `DataGrid` loads from `GET /me/grid-preferences/{gridId}`, falling back to the existing
   `localStorage` value the first time (then PUTs it and removes the local key, a one-time
   migration); saves with a 1 s debounce (`ponytail:` comment: last write wins across tabs).
