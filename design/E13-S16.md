## Requirements (inlined)

- **PO-004 / PO-015** — sends recorded; failures visible, retryable, auditable without duplicating the PO.
- **EML-002 / EML-003 / EML-006** — bounces and complaints surfaced; suppressed never retried silently; provider id, recipient, template, snapshot and result recorded.

## Design

A `Transmissions` card on the detail with one row per send (time, recipient, version, template,
result as a `Signal`), and a sheet per send (provider message id, attempts, events). `Bounced`
shows the next step: `Change Recipient` (the vendor's contacts, with suppressed ones marked) then
`Resend`. `Resend` says it sends **the same version** and commits nothing more. A suppressed
address says it is never retried silently and names the admin page (E13-S21).
