## Requirements (inlined)

- **PO-013 / ACC-006** — release only the unused commitment, once; keep history.

## Design

One dialog with a mode choice: `Cancel the Whole PO` or `Reduce Quantities`. It states the
**released figure** (server), what stays, that the money is **re-reserved for the requisition** by
default (DECISIONS 209), and a checkbox `Also cancel these requisition lines` that changes the
sentence to "returned to <main project>". It also says whether the vendor is told (a checkbox,
default on) and asks for a required reason. Reduce hands off to the change-order screen (E13-S18)
with the quantities prefilled. A cancelled PO stays readable, with the released figure on the detail.
