# E05-S03 — Master data: departments, ledger accounts, UoM, tax codes, payment terms, categories

**Epic** E05 · **M1** · **crud/L** · after **E05-S01** · tags: 

> **Conventions:** read `docs/m1-conventions.md` (authorization outcomes, scope targets, wire formats). It applies unless this packet says otherwise.

## Requirements

- **ORG-010** — Departments, ledger accounts, currencies, units of measure, tax codes, payment terms, and item/service categories must be governed master data.
- **ORG-011** — Master-data records must support effective dates and active/inactive status.
- **ORG-009** — Codes referenced by posted transactions must be deactivated rather than deleted.
- **XFN-009** — Foreign-key fields such as department, ledger account, vendor, project, and item must use scoped dropdown/type-ahead selection rather than free text.

## Design decisions (confirm on review)

- **D-M1-5 Master data is one generic table pair, not eight tables.** `master_record(kind)` with kinds `department`, `ledger_account`, `uom`, `tax_code`, `payment_term`, `item_category`, `service_category`, plus `currency` served read-only from the bundled ISO 4217 data (`kernel/data/iso4217.json`), never stored per tenant. Kind-specific attributes live in a validated `attributes jsonb` whose shape is declared per kind in `modules/org/master_kinds.py` (e.g. `tax_code` requires `rate` as a decimal string; `payment_term` requires `net_days` integer; `uom` requires `dimension`). Rationale: ORG-010 lists seven governed lists with identical lifecycle rules (ORG-009, ORG-011), so one implementation prevents seven drifting ones. A kind that later needs relational structure gets its own table through its own story.

## Contract

Migration (reversible): the next revision after the current head at story start (revision id `20260826_<next 4-digit number>`, `down_revision` = the head `python -m flo.kernel.migrate --check` validates today); stories merge one at a time, so there is no gap or fork: `master_record(id uuid pk, org_id, kind text not null, code text not null, name text not null, attributes jsonb not null default '{}', effective_from date not null default current_date, effective_to date null, active bool not null default true, created_at, updated_at)`; `UNIQUE (org_id, kind, code)`; RLS.

Endpoints (permissions `master.manage`, `master.read`):

- `POST /api/v1/master/{kind}` (Idempotency-Key) → 201 | 409 `duplicate_code` | 422 attribute schema | 404 unknown kind
- `GET /api/v1/master/{kind}?q=&active=&as_of=&cursor=&page_size<=50` → 200 type-ahead capable (prefix match on code and name, server-filtered; this is the XFN-009 scoped dropdown source)
- `PATCH /api/v1/master/{kind}/{id}` (name, attributes, effective dates, active) — **`code` immutable**
- `DELETE` is **not implemented**; `POST /api/v1/master/{kind}/{id}:deactivate` sets `active=false` (ORG-009). A deactivated code remains readable and resolvable for historical documents but is rejected by `assert_usable(kind, code, on_date)` for new transactions.
- `GET /api/v1/master/currency?q=` read-only from bundled data.

Service API other modules call (import `service` only): `master.service.assert_usable(kind, code, on_date) -> MasterRef` raising a typed `MasterCodeUnusable(code, reason in {unknown, inactive, not_effective})`.

## Behaviour

1. Code is stored upper-cased and trimmed; unique per (org, kind).
2. Effective dating: usable on `d` iff `active` and `effective_from <= d` and (`effective_to` is null or `d <= effective_to`).
3. Deactivate is idempotent. Audit every write.
4. The type-ahead query uses an index on `(org_id, kind, code text_pattern_ops)`.

## Acceptance criteria

- [ ] `assert_usable` returns for an active effective code and raises with the correct `reason` for unknown, inactive and not-yet-effective codes
- [ ] There is no route or service path that deletes a master record (a test lists the router's methods and fails on any DELETE under `/master`)
- [ ] `tax_code` without `rate`, with a non-decimal `rate`, or with `rate` as a JSON number is a 422 (money-adjacent values are decimal strings, never floats)
- [ ] The type-ahead endpoint never returns more than 50 rows and filters on the server; a 10,000-record fixture returns the first page without loading the set
- [ ] Foreign-tenant id → 404 on PATCH and deactivate (isolation gate entries)
- [ ] Migration up/down/data-preservation
