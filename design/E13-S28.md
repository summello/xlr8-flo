# E13-S28 — Typed budget effect on a PO change, no hand-written client type

**Epic** E13 · **M3** · **crud/S** · after **E13-S06**, **E13-S18**, **E13-S19** · tags: —
Origin: M3 epic checkpoint E13 (Opus finding 1, 8 Nov 2026).

> **Conventions:** `docs/m1-conventions.md`, `docs/m2-conventions.md`, `docs/author-traps.md`.

## Requirements (inlined)

- **PO-011** — A change order must preserve the prior version, identify changed fields/lines, recalculate budget effects, and be reapproved when policy requires.
- AGENTS.md §3.4: API types are generated from OpenAPI; a hand-written request or response type is a rejection.

## Defect

`PoChangeRead.budget_effect` is `list[dict[str, Any]]` (`apps/api/src/flo/modules/purchasing/schemas.py:372`),
so the generated client has no type for it. `components/purchasing/changes/cards.tsx:6,24` hand-writes
`type Effect` and casts; `components/purchasing/dialogs/CancelOrReduce.tsx:102-103` wraps every field in
`String(...)`. A server rename of `delta` would compile and render "undefined".

## Design

- `PoBudgetEffectRead(BaseModel)`: `project_id: UUID`, `department_code: str | None`,
  `ledger_account_code: str | None`, `currency: str`, `delta: str` (a signed decimal string, as stored; no
  float, no re-rounding). `PoChangeRead.budget_effect: list[PoBudgetEffectRead]`. Validate the stored rows
  through it on read; the stored JSON shape does not change and needs no migration.
- **The approval material digest must not change:** `purchasing/approval.py` ~127 hashes
  `json.dumps(change.budget_effect, sort_keys=True)`. Dump the models back to the identical dicts
  (`model_dump(mode="json")`) before hashing, so an in-flight approval's digest is unchanged.
- Regenerate the client; delete the local `Effect` type and the `String()` wrappers in both components.
- `diff` stays `list[dict]` (its value types vary by field); out of scope.

## Acceptance

- [ ] pytest: a PO change read returns `budget_effect` items with exactly the five fields; `delta` is a string equal to the stored value (including a negative).
- [ ] pytest: the approval digest for a seeded change is byte-identical before and after this story (golden value computed on the pre-story code).
- [ ] `tsc` passes with no cast or local type for the effect; existing change-order and cancel/reduce Playwright specs green.
- [ ] `flo check --light` green.

## Plants

1. Rename `delta` to `amount` in the model: `tsc` fails in both components.
2. Hash the models' default `model_dump()` (UUID objects): the digest golden test fails.
