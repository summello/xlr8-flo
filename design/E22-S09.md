# E22-S09 — Show people by name, with the email as secondary text

**Epic** E22 · **M3** · **ui/M** · tags: ui

> Operator decision, 21 Oct 2026: canvas DECISIONS **232** (amends D-M2-16). Depends on **E22-S07**,
> which returns a `*_name` beside every person's email. Read `design-system/MASTER.md` before
> starting; the canvas boards that show email only are stale on this point.

## Requirements (inlined)

- **A11Y-004** — Information is never carried by colour alone.
- **UX-007** — Locale-correct display with canonical values preserved (the email stays the canonical identifier).

## Design

**One component.** `apps/web/src/components/ui/Person.tsx` exports:

- `Person({ name, email }: { name: string | null; email: string })`: with a name, a `<span class="person">`
  holding the name (`--fg`, the inherited body size) then the email (`--fg-secondary`) in their own
  spans; `title` is `"<name> <email>"`. Without a name (or an empty/whitespace one): the email alone,
  exactly as today, `title` the email. No avatar, no initials.
- `personLabel(name: string | null, email: string): string`: `"<name> (<email>)"`, or the email alone.
  For places that accept text only: a native `<option>`, an `aria-label`, a template-string sentence
  (`requested by …`, `You Are Covering For …`).

**Layout without a breakpoint.** `.person` is `display: inline-flex; flex-wrap: wrap; column-gap:
var(--space-2); min-width: 0; max-width: 100%`; each part is `overflow: hidden; text-overflow:
ellipsis; white-space: nowrap; min-width: 0`. The email wraps below the name when the container is
narrower than both, at any width. **No media query and no px value**; style it in the
existing stylesheet the shared ui components already use (no new CSS file), with tokens only.

**Adoption: the inventory.** Every person shown by email moves to `<Person>` (element positions) or
`personLabel` (text-only positions). The API already returns the name beside each email
(E22-S07: `*_name` for `*_email`, `display_name` or `name` for a bare `email`; `PickerRow` is
`{user_id, email, name}`). The sites, from `grep -rnoE '\.([a-z_]+_)?email\b' apps/web/src --include='*.tsx'`
on 24 Oct 2026:
