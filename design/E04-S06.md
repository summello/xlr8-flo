# E04-S06 — Material layer: tinted shadows, lit edge, grain, honest glass, glow focus ring

**Epic** E04 · **M0** · **ui/M** · after **E04-S01** · tags: `ui`

## Requirements

- **UX-006** — Light and dark modes must be supported without weakening semantic color or contrast.
- **A11Y-005** — Text, controls, focus indicators, and non-text UI must meet applicable contrast requirements.

## Deliverable

`design-system/MASTER.md` §3 implemented as five utilities. These are the difference between "a Bootstrap admin panel" and "an instrument", and each is honest — it either renders a surface truthfully or communicates something.

## Behaviour

1. **Tinted shadows.** Every shadow is tinted with the canvas hue and layered — a tight contact shadow plus a wide ambient one. Pure-black shadows are why most enterprise UI looks muddy. In dark mode, surfaces do not cast: depth comes from the lit edge, and shadows are near-black and subtle.
2. **Lit edge.** `inset 0 1px 0 0 rgb(255 255 255 / .9)` in light, `/ .06` in dark. One inset hairline does more for perceived quality than any gradient.
3. **Grain.** A fixed-position 2.5 %-opacity inline SVG noise layer, `mix-blend-mode: overlay`, ~400 bytes, no network request. Hidden under `prefers-reduced-transparency: reduce`.
4. **Glass — only where something is behind it.** Exactly three places: the sticky grid header, the command palette, the sheet backdrop. `backdrop-filter: blur(20px) saturate(180%)`. **The `saturate(180%)` is not optional** — without it, colour behind glass desaturates and the effect reads as fog. Two fallbacks required: `@supports not (backdrop-filter)` → opaque surface, and `prefers-reduced-transparency: reduce` → opaque surface.
5. **Glow focus ring.** 2 px solid ring, 2 px offset, plus a 6 px soft glow at 18 % alpha. Never removed, never clipped by `overflow: hidden` on an ancestor.

## Constraints

- These are **utilities in CSS**, consuming tokens from E04-S01. No component hardcodes a shadow.
- Decorative layers must not intercept pointer events (`pointer-events: none`) or affect layout.
- Glass must never reduce text contrast below 4.5:1 against what shows through — tested against both the lightest and darkest content that can sit behind it.
- Nothing here may convey information. Removing every effect must leave the interface fully usable, which is what makes them safe to disable under user preferences.

## Acceptance criteria

- [ ] No shadow uses pure black; each is tinted and layered
- [ ] Dark mode uses the lit edge for depth, not a cast shadow
- [ ] Grain renders at ≤3 % opacity, is `pointer-events: none`, and disappears under reduced transparency
- [ ] Glass appears in exactly three places; a fourth use fails a CI grep
- [ ] `saturate(180%)` present on every glass surface
- [ ] With `backdrop-filter` unsupported, glass falls back to an opaque surface with unchanged contrast
- [ ] Text over glass measures ≥4.5:1 against both the lightest and darkest possible backdrop content
- [ ] Focus ring is visible on every interactive element in both themes and is never clipped
- [ ] Disabling all five utilities leaves the interface fully usable and passes axe
- [ ] No component file contains a `box-shadow` literal — CI grep proves it
