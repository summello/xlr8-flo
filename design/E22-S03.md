# E22-S03 — One audit helper instead of twelve

**Epic** E22 · **M3** · **chore/M** · tags: none

> From the Opus M2 milestone review (major). Decision 13 (D-M2-28).

## Design
Twelve module-local `_audit` wrappers restate actor kind, outcome and field handling over
`kernel.audit.AuditWriter`: `collaboration/service.py:102`, `identity/service.py:439`,
`identity/invitation.py:220`, `org/service.py:164`, `org/fiscal.py:80`, `requisitions/service.py:244`,
`requisitions/amendments.py:88`, `projects/service.py:193`, `imports/service.py:192`,
`approvals/service.py:244`, `approvals/decisions.py:166`, `approvals/delegation.py:250`.
Add one function in `kernel/audit` and replace all twelve. **Behaviour-preserving:** identical audit rows;
`audit_log` append-only; no existing row touched.

- [ ] A parametrized test: one representative command per module writes a byte-identical audit row before and after.
- [ ] import-linter green; plant: drop a field in the helper and the test fails.
