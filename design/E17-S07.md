## Design

### 1. Glossary (`apps/web/src/help/terms.ts`)

`export const TERMS = { allocated: {term: "Allocated", text: "…"}, … } as const satisfies Record<string, {term: string; text: string}>`
and `export type HelpTermId = keyof typeof TERMS`. One plain-language sentence or two per term, ≤ 240
characters, no jargon the sentence does not explain. Seed it with every term the covered surfaces
show: the five budget buckets plus variance and consumption percentage (definitions match the KPI
registry text in E15-S01 where it exists; if E15-S01 has not merged, write them from
`docs/requirements.md` RPT-003 and FIN definitions), funding mode (roll-down / roll-up), sub-project,
each requisition status in `docs/m2-conventions.md` §J, reservation, commitment, actual, every grid
column shown today, and each `<dt>` above. Copy that is not settled by the requirements: write the
conservative version and list the terms in `notes.followup` for the operator's copy review.

### 2. `HelpTip` (`apps/web/src/components/help/HelpTip.tsx`): a toggletip, not a hover tooltip

```tsx
<HelpTip term="committed" />     // renders the trigger; the term's label stays outside it
```

- Trigger: a `<button type="button">` with Phosphor `Info` (regular, `--icon-inline`, 16px per §7.10), `aria-label="About {term}"`, `aria-expanded`, `aria-controls`. Hit area
  `--touch-target` below 1024px (MASTER §8), the icon unchanged. Visible focus ring per §3.5.
- Opens on click, `Enter` or `Space`; closes on `Esc` (focus returns to the trigger), on a second
  activation, and on pointer-down outside. **Not on hover** (avoids the WCAG 1.4.13 traps and works on
  touch). One open at a time per page.
- Bubble: an element with `role="status"` (so the text is announced when it opens) beside the
  trigger, `--raised` ground, 1px `--border`, `--radius-control`, `--shadow-md`, padding
  `--space-2` `--space-3`, Caption type (12/16), `--fg`, `max-width` `calc(var(--space-8) * 6)`,
  `z-index: var(--z-tooltip)`; it repositions to stay inside the viewport at 375px (flip below/above,
  clamp horizontally); never causes horizontal page scroll.
- Motion: MASTER §6.3 "Popover" (scale 0.97→1 and fade, `transform-origin` at the trigger, enter
  `--ease-out`). §6.3 states 150ms but **no token holds 150ms**: use `--dur-fast` and record the gap
  in `notes.followup` (the handoff lists it for the design session). Under reduced motion, opacity
  only (§6.4).

### 3. Coverage, enforced by the type system

- `GridColumnMeta` gains **required** `help: HelpTermId`. `components/grid/Header.tsx` renders
  `<HelpTip term={meta.help} />` after the label, outside the sort button (a button never nests in
  a button). `tsc` then fails on any grid column without help: that is the gate.
- `Kpis.tsx`: restructure each card so the label row holds the `HelpTip` **outside** the `<a>` (a
  link containing a button is invalid); the link keeps the value and as-of line. Add a required
  `help: HelpTermId` to each bucket entry.
- A `KeyValue` component (`components/help/KeyValue.tsx`: `<div><dt>{label} <HelpTip term={help}/></dt><dd>{children}</dd></div>`,
  `help` required) replaces the bare `<dt>/<dd>` pairs in the files listed under Today. Terms that
  explain nothing (a record number) may pass `help={null}` explicitly, so omission is never silent.
- A vitest walks `TERMS` and fails on an empty text, a text over 240 characters, or a term id used
  in `src/` that is not in `TERMS` (the type already catches this; the test catches stale entries
  nobody uses: every key in `TERMS` must be referenced at least once).

### 4. Screens covered

Every route in `apps/web/src/routes/route-paths.ts` that renders content today, except `/_dev/*`:
forms via `Field` (already), grids via column meta, dashboards via KPI cards, details via
`KeyValue`. `/help/keyboard` is itself help. Placeholder routes with no content yet
(`/reporting`, `/sourcing`, `/purchase-orders`, `/assets`, `/views/archive` if still placeholders)
are skipped and listed in the e2e as such, so the next story that fills one inherits the column and
`KeyValue` types.

- [ ] `tsc` fails when one grid column omits `help` and when one `KeyValue` omits `help` (plants below).

- [ ] The KPI card markup has no interactive element inside the `<a>` (axe `nested-interactive` passes).

- [ ] The glossary vitest passes; tokens only (no raw hex, `oklch()`, px literal for colour, radius, spacing or duration outside `tokens.css`; the bubble's `max-width` uses the expression above).
