# E03-S06 — Job queue (SKIP LOCKED), outbox, cron tick endpoint, Storage and Email ports

**Epic** E03 · **M0** · **engine/L** · after **E03-S04** · tags: `security`

## Requirements

- **ARCH-006** — External effects such as email/API delivery must use a transactional outbox or equivalent durable handoff.
- **REL-007** — Background jobs must retry transient failures with bounded backoff and route exhausted failures for operator review.
- **PERF-004** — Imports, complex reports, bulk exports, email delivery, and recalculation must run as background jobs with visible progress.
- **COL-006** — Files must be stored outside the public web root and downloaded through an authorized, time-limited path or application response.
- **D-07** — Cloudflare R2 behind a `Storage` port. **D-08** — Postgres queue, no broker. **D-10** — Resend behind an `EmailSender` port.

## Deliverable

Everything asynchronous, on a platform that scales to zero. The design constraint that shapes this story: **there is no always-on worker**, because Cloud Run runs at `min-instances=0`.

## Model

```sql
CREATE TABLE job (
  id, org_id, kind, payload JSONB, state,           -- queued|running|done|failed|dead
  attempts INT NOT NULL DEFAULT 0, max_attempts INT NOT NULL DEFAULT 5,
  run_after TIMESTAMPTZ NOT NULL DEFAULT now(),
  locked_at TIMESTAMPTZ, last_error TEXT,
  correlation_id TEXT NOT NULL, progress JSONB
);
CREATE TABLE outbox (
  id, org_id, topic, payload JSONB, state,          -- pending|sent|failed|dead
  attempts INT, run_after TIMESTAMPTZ, provider_message_id TEXT,
  idempotency_key TEXT NOT NULL, correlation_id TEXT NOT NULL
);
```

## Behaviour

1. **Claim with `SKIP LOCKED`** so concurrent ticks never process the same job:
   ```sql
   UPDATE job SET state='running', locked_at=now(), attempts=attempts+1
   WHERE id = (SELECT id FROM job
               WHERE state='queued' AND run_after <= now()
               ORDER BY run_after FOR UPDATE SKIP LOCKED LIMIT 1)
   RETURNING *;
   ```
2. **Outbox rows are written in the same transaction as the business change** (ARCH-006). A PO that commits without its send row, or sends without committing, is the failure this pattern exists to prevent.
3. **Driven by cron, not a daemon** — `POST /internal/jobs/tick` processes for up to 50 s then returns a summary. A Cloudflare Worker cron trigger calls it every 60 s (free tier). The endpoint authenticates with a shared secret from Secret Manager and is **not** reachable from the public router.
4. **Retry (REL-007)** — exponential backoff with jitter: 1 s, 4 s, 16 s, 64 s, 256 s. After `max_attempts` the row moves to `dead`, never silently dropped, and surfaces on the operator view. Only transient errors retry; a validation error goes straight to `dead`.
5. **Exactly-once external effect** — each outbox row carries an `idempotency_key` passed to the provider, so a retry after an ambiguous timeout does not send a second email. `provider_message_id` is recorded on success (EML-006).
6. **`Storage` port** — `put`, `get`, `presign_get(ttl)`, `delete`. R2 adapter for deployment, MinIO for local. Objects are private; downloads go through a short-TTL presigned URL or an authorized application response, never a public path (COL-006). Keys are opaque UUIDs, never user-supplied filenames.
7. **`EmailSender` port** — `send(to, template, context, idempotency_key)`. Resend adapter plus an SMTP adapter for local Mailpit. Swapping providers is a config change (D-10).
8. `progress` is a JSONB `{current, total, message}` the UI polls (PERF-004).
9. Ports live in `kernel/` and are the only way modules reach the outside world. `lint-imports` forbids a module importing `boto3` or an HTTP client directly.

## Acceptance criteria

- [ ] Two concurrent ticks never process the same job — asserted with 100 jobs and 4 workers, each executed exactly once
- [ ] A job failing 5 times lands in `dead` with `last_error`, and appears on the operator view
- [ ] Backoff delays follow 1/4/16/64/256 s with jitter
- [ ] A validation error goes to `dead` on the first attempt, without retrying
- [ ] An outbox row and its business change commit or roll back together
- [ ] Simulated provider timeout, then retry, produces **one** delivered email — verified via the provider idempotency key
- [ ] `provider_message_id` is recorded on success
- [ ] `/internal/jobs/tick` rejects an unauthenticated call and is absent from the public OpenAPI document
- [ ] A presigned URL expires; the object is not publicly readable without one
- [ ] `correlation_id` from the originating request appears on the job's audit rows
- [ ] A module importing `boto3` directly fails `lint-imports`
