# E22-S08 — Expired requisitions use the warning tone

**Epic** E22 · **M3** · **ui/S** · tags: ui

> Operator decision, 21 Oct 2026: canvas DECISIONS **231**; MASTER §2.3 amended the same day.
> The requisition map is `rejected` danger, `withdrawn` neutral, **`expired` warning** (recoverable
> by resubmitting, not an error). E09-S11 shipped `expired` as danger. `status/map.ts` follows MASTER,
> never the reverse.

## Requirements (inlined)

- **A11Y-004** — Colour never carries meaning alone; status needs an icon or text too.

## Design

`apps/web/src/components/status/map.ts`: `requisition.expired` → `"warning"`. The pill then shows
`--status-warning` with the `Warning` icon and the `Expired` text (MASTER §2.3), so the meaning is
carried by icon and text in both themes.
