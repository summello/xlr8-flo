# E01-S01 — Monorepo skeleton, tooling, ruff/mypy/eslint/tsc config

**Epic** E01 Platform & delivery · **Milestone** M0 · **chore/M** · no dependencies

## Requirements

- **COMP-004** — Deployments must externalize configuration and avoid environment-specific code branches.

## Deliverable

The directory skeleton and the single quality entry point every later story depends on. No application logic.

```
apps/api/
  pyproject.toml            # project + [dev] extra, ruff/mypy/pytest config
  src/flo/__init__.py
  src/flo/kernel/__init__.py
  src/flo/modules/__init__.py
  src/flo/api/__init__.py
  tests/__init__.py
apps/web/
  package.json  tsconfig.json  vite.config.ts  eslint.config.js
  src/main.tsx  src/App.tsx  index.html
.importlinter                # module boundary contracts
```

## Behaviour

1. `apps/api` is an installable package (`pip install -e 'apps/api[dev]'`) exposing `flo`.
2. Configuration is read **only** from environment variables through one `kernel/config.py` using Pydantic `BaseSettings`. No `if ENV == "prod"` branch may exist anywhere — that is COMP-004, and CI will enforce it from E01-S04.
3. `ruff` and `mypy --strict` cover `apps/api/src/flo`. `eslint` and `tsc --noEmit` cover `apps/web/src`.
4. `.importlinter` declares the layered contract now, even though the modules are empty:
   - `flo.api` may import `flo.modules.*` and `flo.kernel`
   - `flo.modules.*` may import `flo.kernel` only
   - no `flo.modules.X` may import `flo.modules.Y`
5. `agents/scripts/flo check` runs green against the empty skeleton.

## Acceptance criteria

- [ ] `pip install -e 'apps/api[dev]'` succeeds from a clean venv
- [ ] `ruff check apps/api` exits 0
- [ ] `mypy --strict apps/api/src/flo` exits 0
- [ ] `npm --prefix apps/web ci && npm --prefix apps/web run typecheck` exits 0
- [ ] `lint-imports` exits 0 and **fails** when a deliberate `flo.modules.a → flo.modules.b` import is added, then passes when removed
- [ ] `grep -rE 'ENV ==|NODE_ENV ===' apps/` returns nothing
- [ ] `flo check` reports every tool as present and green
