## The pre-flight technique (what cost E05-S10 seven rounds)

Every codex block on S10 was a real gap in the packet, found only after dispatch. Before dispatching, for each packet, check against the repo, not against the packet's own claims:

1. **Names that exist.** The router, middleware, permission, table, setting, ErrorCode, helper the packet cites. (S10 named a router the app does not use.)
2. **Gates in the request path.** Middleware that will reject the new route's requests before the handler runs: CSRF, the MFA gate, idempotency, the origin secret. (S10's session probe; the cron tick.)
3. **Tenancy of the infrastructure.** `job` and `outbox` are tenant-scoped (`org_id NOT NULL`, RLS). Anything global cannot be a queue row.
4. **Who calls it, and when.** A job nobody schedules does not exist. The cron Worker only ticks and checks quota unless a story changes it.
5. **Dependencies in the production image,** not the dev environment. `httpx` is dev-only.
6. **Tokens and literals.** Every value the page states numerically against `tokens.css`; decide `--auth-*`-style feature properties up front.
7. **Test assets that must be authored,** because codex has no network (fixtures, golden values). Compute golden values yourself.
8. **Linux CI.** No absolute macOS paths in tests; the generated-client gate builds from `uv.lock`.
9. **Closed taxonomies.** `ErrorCode` is closed; map to existing codes with a `checks={"problem": ...}` label.
10. **A "defer, do not block" rule.** Codex blocks only for money, authorization, session, state-transition, or a value the packet does not state.

## Rules learned this session

- A CSRF exemption was blocked by the safety classifier as weakening a control. Do not retry it another way. Make clients take part in the protocol (the cron Worker now sends its own CSRF pair and an `Idempotency-Key`).
- The classifier also once denied a read-only `grep` right after a push. Do not work around a denial; use a different, safer method or stop and ask.
- `AuditActor(USER, None)` raises. Services constructed without `actor_id` fail with a 500 on mutating calls (recorded, not fixed).
- Release reviewers: one at a time in a detached checkout, isolated `XDG_DATA_HOME`, key read from the keychain at the point of use (`.scratch/release-review.sh`). A stall monitor beats a plain exit monitor.
- Authority for UI values: MASTER and `tokens.css`, then the page file, then the canvas for layout only (AGENTS.md).
- Never run two database suites at once, and never reset the DB under a running gate.
